# Tradersho panel

React/Vite، Node.js 24 و PostgreSQL. ثبت‌نام/ورود، داشبورد، صفحات خدمات و محیط مستقل چارت/Replay.

## اجرا

```bash
npm ci
export DATABASE_URL='postgresql://localhost:5432/tradersho_dev'
npm run dev
```

ابتدا دیتابیس را بسازید. سرور در شروع جداول را به‌صورت افزایشی ایجاد می‌کند. Vite روی `http://127.0.0.1:5173`، API روی پورت 3001 و proxy `/api` است. متغیرهای محیط را صریح export کنید؛ فایل `.env.example` نمونه است و `.env` خودکار بارگیری نمی‌شود.

## Production

```bash
npm run build
NODE_ENV=production npm start
```

`DATABASE_URL` الزامی، `PORT` پیش‌فرض 3001 و `HOST` پیش‌فرض `0.0.0.0` است. در production سرور Node فایل‌های `dist` و API را در یک مبدأ سرو می‌کند. بررسی سلامت: `/api/health`؛ پاسخ سالم `{"ok":true,"database":"ready"}` است. Dockerfile شامل `server/`، `shared/` و build فرانت‌اند است. دیتابیس و secrets باید توسط میزبان فراهم شوند و در Git قرار نگیرند. برای انتشار عمومی از HTTPS استفاده کنید.

## وضعیت امکانات

- ثبت‌نام با تکرار رمز، حداقل ۸ کاراکتر شامل حروف کوچک/بزرگ، عدد و کاراکتر خاص؛ نشست در دیتابیس، تغییر رمز و خروج از همهٔ نشست‌ها. تأیید ایمیل و بازیابی رمز در این نسخه وجود ندارند.
- کیف پول پایه، ثبت تیکت و درخواست بررسی ریبیت؛ بدون درگاه، اتصال بروکر یا تسویهٔ واقعی. اشتراک موقتاً غیرفعال است. ابزارها و دوره‌های منتشرنشده «به‌زودی» هستند.
- `/panel/tools/chart`: کندل، ۹ تایم‌فریم، شش نمایش، ۲۷ ترسیم، ۱۵ اندیکاتور، دو نما، تمام‌صفحه و ذخیرهٔ تنظیمات/جلسه.
- **دادهٔ پیش‌فرض مصنوعی است**؛ ۴۳٬۲۰۰ کندل M1 برای تمرین رابط، نه تاریخچهٔ بازار. CSV شخصی فقط EUR/USD یک‌دقیقه‌ای، UTC، ۵۱ تا ۳۰٬۰۰۰ کندل، حداکثر پنج مگابایت و پنج فایل در حساب می‌پذیرد. مالکیت فایل و جلسه در سرور کنترل می‌شود.
- Replay از prefix آشکار استفاده می‌کند؛ تایم‌فریم بزرگ‌تر از همان دقیقه‌های آشکار تجمیع می‌شود. تغییر تایم‌فریم زمان را تغییر نمی‌دهد. آخرین کندل می‌تواند ناقص باشد.
- حساب فرضی: سرمایهٔ اولیه، خرید/فروش، SL/TP، تاریخچه و CSV معاملات. بازار در Open دقیقهٔ بعد اجرا می‌شود؛ تمام دقیقه‌های گام تایم‌فریم بزرگ پردازش می‌شوند. اگر SL و TP در یک M1 لمس شوند، حد ضرر اولویت دارد؛ گپ با Open اجرا می‌شود. اهرم ۱:۱، بدون اسپرد/کارمزد/swap و margin call. این شبیه‌سازی بک‌تست دقیق بروکر نیست.
- `/panel/tools/chart?view=reference`: نسخهٔ جدا با ۲۵۵ نرخ مرجع روزانهٔ EUR/USD در ۲۰۲۵ از ECB، نمودار خطی و اجرای فرضی در نرخ انتشار بعدی. OHLC یا Live نیست. منبع/شرایط در رابط مشخص است.
- Pine Script، کل مجموعهٔ ابزارهای TradingView، feed زنده، اسکنر و هشدار پس‌زمینه اجرا نمی‌شوند. هستهٔ نمایش Lightweight Charts با انتساب و فایل Apache 2.0 است.

## بررسی

```bash
npm run build
npm run test:unit
```

تست واحد با Node 24 فایل TS را مستقیم اجرا می‌کند. E2E به Google Chrome نصب‌شده و دیتابیس QA **جدا** نیاز دارد. محیط QA را مثلاً در پورت 5183 با `DATABASE_URL` دیتابیس تست، `HOST=127.0.0.1` و `NODE_ENV=production` اجرا کنید، سپس:

```bash
E2E_BASE_URL=http://127.0.0.1:5183 npm run test:e2e
npm run test:e2e:candles
```

تست‌های کندلی برای جلوگیری از اجرای اشتباه روی کاربران واقعی، فقط پورت 5183 را می‌پذیرند. آزمون‌ها حساب‌های آزمایشی ایجاد می‌کنند. `qa/` و داده‌های محلی در Git نیستند. CI روی GitHub فقط build و تست‌های واحد را اجرا می‌کند و به دیتابیس واقعی دسترسی ندارد.

# Tradersho brand webfonts

Yekan Bakh is the Persian typeface specified in the Tradersho brandbook. These four WOFF files were obtained on 2026-10-20 from Tradersho's own existing website for use in this brand's panel:

- https://tradersho.com/wp-content/uploads/2026/05/YekanBakhFaNum-Light.woff
- https://tradersho.com/wp-content/uploads/2026/05/YekanBakhFaNum-Regular.woff
- https://tradersho.com/wp-content/uploads/2026/05/YekanBakhFaNum-SemiBold.woff
- https://tradersho.com/wp-content/uploads/2026/05/YekanBakhFaNum-Bold.woff

The declarations were found in https://tradersho.com/wp-content/uploads/elementor/css/post-6.css. Actual font weights are mapped to Light 300, Regular 400/500, SemiBold 600, Bold 700+ in this panel. No font was extracted from the brandbook PDF.

Yekan Bakh is a commercial typeface by Fontiran: https://fontiran.com/fonts/yekan-bakh. Reusing the existing brand assets does not create a general redistribution license. These font binaries are deployment assets for the Tradersho panel; do not distribute them as a font package or publish them to the public Git repository without the brand's license allowing that distribution. Gilroy, the separate Latin brand typeface, has not been supplied or bundled; do not label a fallback as Gilroy.

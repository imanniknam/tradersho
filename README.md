# Tradersho

پنل مستقل کاربری «تریدر شو» با React، Vite، Node.js و PostgreSQL. این مخزن شامل کد پنل، چارت و Replay و دارایی‌های لازم برای اجرای برنامه است.

## امکانات فعلی

- ثبت‌نام و ورود با ایمیل/رمز قوی، نشست سمت سرور، تغییر رمز و خروج از نشست‌ها.
- داشبورد، کیف پول پایه، ثبت درخواست ریبیت و پشتیبانی؛ بخش‌های آماده‌نشده با وضعیت «به‌زودی».
- محیط کندلی با ۹ تایم‌فریم، ۲۷ ابزار ترسیم، ۱۵ اندیکاتور، دو نما و تمام‌صفحه.
- Replay با حساب فرضی، خرید/فروش، حد ضرر/هدف، تاریخچه و خروجی معاملات.
- ورود فایل شخصی OHLC با کنترل مالکیت و ذخیرهٔ پیشرفت/تنظیمات در PostgreSQL.

**دادهٔ پیش‌فرض چارت کندلی مصنوعی و مخصوص دمو است؛ دادهٔ Live یا تاریخچهٔ بروکر نیست.** نسخهٔ جداگانهٔ نرخ مرجع واقعی ECB در `/panel/tools/chart?view=reference` باقی است. این پروژه همهٔ امکانات TradingView یا Pine Script را اجرا نمی‌کند. حساب تمرینی به کیف پول واقعی یا بروکر متصل نیست.

## اجرای محلی

پیش‌نیاز: Node.js 24، npm و PostgreSQL.

```bash
cd app
npm ci
cp .env.example .env
```

یک دیتابیس PostgreSQL بسازید و `DATABASE_URL` را در `app/.env` تنظیم کنید. هنگام اجرای اسکریپت‌ها این متغیر باید در محیط Node موجود باشد؛ نمونهٔ زیر متغیر اتصال را صریح تنظیم می‌کند:

```bash
export DATABASE_URL='postgresql://localhost:5432/tradersho_dev'
npm run dev
```

صفحهٔ محلی Vite: `http://127.0.0.1:5173`. جداول با اجرای سرور به‌صورت افزایشی ساخته می‌شوند. حساب‌های دیتابیس محلی یا داده‌های کاربران در این مخزن قرار ندارند؛ برای محیط تازه ثبت‌نام کنید.

## ساخت و بررسی

```bash
cd app
npm run build
npm run test:unit
```

تست مرورگری به Chrome و یک دیتابیس QA مستقل نیاز دارد؛ روی دیتابیس کاربران اجرا نکنید. راهنمای آزمون و اجرای production در [app/README.md](app/README.md) است.

## استقرار

فایل `app/Dockerfile` فرانت‌اند و API را در یک سرویس اجرا می‌کند. `DATABASE_URL` الزامی است؛ `PORT` و `HOST` در صورت نیاز از محیط گرفته می‌شوند. مسیر بررسی سلامت `/api/health` است. `render.yaml` پیکربندی اولیهٔ Blueprint است؛ حساب میزبان، پایگاه‌داده و تنظیمات محیطی باید جداگانه فراهم شوند.

قرارگرفتن کد در GitHub به‌تنهایی وب‌اپ و PostgreSQL را میزبانی نمی‌کند. این مخزن حاوی اطلاعات ورود، فایل‌های `.env`، دیتابیس مک یا `node_modules` نیست.

## راهنمای فنی

جزئیات اجرا، متغیرهای محیطی و مرز امکانات در [app/README.md](app/README.md) آمده است. برندبوک، اسناد داخلی محصول و اطلاعات محیط‌های محلی در مخزن عمومی قرار نمی‌گیرند.

حقوق برند و دارایی‌های Tradersho متعلق به صاحبان آن‌هاست. انتشار این مخزن به معنی اعطای مجوز استفاده از برند یا تغییر مجوز وابستگی‌ها نیست. انتساب Lightweight Charts و Apache 2.0 در [فایل مجوز](app/public/licenses/lightweight-charts.txt) حفظ شده است.
